# HTML 문서 공유 사이트

이 폴더의 `index.html`을 GitHub 저장소에 올리면 GitHub Pages가 공개 웹사이트로 배포합니다.

## 문서 수정과 배포

1. `index.html`을 수정합니다.
2. GitHub 저장소 페이지에서 파일을 업로드하거나 내용을 편집합니다.
3. 변경 사항을 `main` 브랜치에 저장합니다.
4. 약 1~2분 뒤 공개 주소에서 변경 사항을 확인합니다.

## 배포 주소

GitHub Pages를 설정한 뒤 다음 형식의 주소를 사용합니다.

`https://lloyd-droid.github.io/github-pages-site/`

## 주의

이 저장소는 공개로 만들 예정입니다. 개인정보, 비밀번호, 성도 연락처·상담 기록 등 비공개 정보는 올리지 마세요.
